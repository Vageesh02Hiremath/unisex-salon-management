# Project Demo Video Script

## Title Slide
- Show the project name: **Unisex Salon Management System**
- Mention: "Live demo of project output for GitHub presentation."
- Optional: include your name and date.

## 1. Introduction (10-15 seconds)
- Show the home page `index.php` and app branding.
- Narration: "This is the completed Unisex Salon Management System built with PHP, MySQL, AJAX, and Chart.js."
- Mention the supported user roles: Admin, Staff, Customer.

## 2. Customer Workflow (30-45 seconds)
- Show `customer/services.php`.
- Choose a service category (Male / Female / Kids / Unisex).
- Demonstrate filtering services with AJAX.
- Navigate to `customer/book_appointment.php`.
- Fill booking details: service, staff, appointment date, time slot.
- Complete booking and show confirmation or `customer/my_appointments.php`.
- Narration points:
  - "Customers can browse salon services by gender category."
  - "Appointments use AJAX to validate available staff and slots."

## 3. Admin Workflow (40-60 seconds)
- Login as admin and show `admin/dashboard.php`.
- Open key pages:
  - `admin/appointments.php`
  - `admin/customers.php`
  - `admin/services.php`
  - `admin/reports.php`
- Show a service edit/add screen if available.
- Show revenue chart or report view from `admin/revenue_chart.php`.
- Narration points:
  - "Admin can manage appointments, services, customers, and generate reports."
  - "Revenue charts are generated with Chart.js."

## 4. Staff Workflow (25-30 seconds)
- Login as staff and show `staff/dashboard.php`.
- Open `staff/assigned_appointments.php`.
- Show appointment status updates or schedule view.
- Narration points:
  - "Staff can view assigned appointments and update appointment statuses."

## 5. Billing and Payment (20-30 seconds)
- Show `customer/my_bills.php` or `admin/bills.php`.
- Briefly mention Razorpay integration and pay-at-salon option.
- Narration points:
  - "Bills are generated automatically when appointments are completed."
  - "Online payments are supported through Razorpay when keys are configured."

## 6. Closing (10-15 seconds)
- Summarize core features:
  - Role-based panels
  - Appointment booking
  - Billing and payments
  - Reports and charts
- End with: "The Unisex Salon Management System is complete and ready for GitHub showcase."
- Optionally mention the demo video file name.

## Recording Tips
- Record at 1080p if possible.
- Keep the screen clean and close unrelated tabs.
- Use a quiet environment for narration.
- Save the final file as `salon-system-demo.mp4` for GitHub.
- Add the video or link in `README.md`.
